# Cyberpunk 2077 Case Study

This is a standalone HTML, CSS, and JavaScript version of the interactive
presentation site.

## Open locally

Double click `index.html` or open it in a modern browser.

For the most reliable local preview, run a simple local server in this folder:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Files

* `index.html` contains the page shell and metadata.
* `style.css` contains the complete responsive cyberpunk visual system.
* `script.js` contains the interface, animations, audio, navigation, bug triage,
  risk register, launch gates, and release board.
* `section-navigation.js` adds the next-section controls and presentation pacing.
* `cyber-media/` and `presentation-assets/` contain the site imagery.
